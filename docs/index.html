The notch, finally useful.

A dynamic island for the MacBook notch. Glanceable state in two wings, overlays that grow out of the notch for a moment, and an expanded view when you want more. Above every window, even the lock screen.

Build it in a minute View on GitHub

Eighteen plugins. Pick one.

Each is a switch in Settings. Twelve are built in; six are ordinary plugins you could have written yourself. Tap one to see how the island shows it.

How it works

Two independent wings

An overlay claims the left side, the right, or both. Whatever it doesn't claim keeps its content and its width, measured from what it holds.

Above everything

The panel sits in its own WindowServer space at the lock-screen level, via SkyLight, so it stays over full-screen apps and the login window.

Click-through

It only takes the mouse while the cursor is over the island. The rest of the strip belongs to whatever is underneath.

Honest motion

Icons change in place rather than swapping: a padlock opens, a cover flips, a slash draws across a speaker.

Write your own, in anything.

A plugin is a folder with a manifest and a program that prints JSON lines. Bash, Python, Swift, Go, whatever you like. The island draws it with the same badges, overlays and sections as everything else.

# plugin.json
{ "protocol": 1, "id": "coffee", "name": "Coffee", "symbol": "cup.and.saucer.fill", "run": "coffee.sh" }

# coffee.sh
read start
echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "2"}]}}'
echo '{"hud": {"symbol": "cup.and.saucer.fill", "tint": "orange", "text": "Coffee logged"}}'
echo '{"section": {"title": "Coffee", "rows": [{"id": "log", "title": "Log a cup"}]}}'

Drop the folder into the plugins folder from Settings and it's running. Six of the plugins above, weather, downloads, timer, clipboard, shelf and agents, are written exactly this way. The protocol is in the README.

Install

macOS 14 or later, on a Mac with a notch.

# clone, build a release bundle and launch it
git clone https://github.com/zenodea/controlisland.git
cd controlisland
make open

# run the tests
make test

Right-click the island for Settings, including Open at login. Each plugin asks for its permission the first time it needs one, and each can be switched off.
