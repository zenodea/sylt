Sylt

A dynamic island for the MacBook notch. Status in two wings, short overlays for changes, and an expanded view with controls. It stays above every window, including the lock screen.

Install View on GitHub

Features

Closed, the island hugs the notch and shows only live state in two wings. Changes show as short overlays out of the notch; each kind can be switched off in Settings, and a slider sets how long they stay. Select anything to see it on the island.

Expanded

Click or swipe down and the island opens on what is relevant, two sections to a page; swipe sideways to turn it. A setting opens two pages side by side, or three on a wide display, when the screen has room. A section's title opens the app it stands for, such as Activity Monitor for system load; the event opens Calendar and the artwork the player.

Plugins

Everything else is a program that prints JSON, in any language, drawn with the same badges, overlays and sections. Fifteen are included; each can be switched off, and its overlays separately.

Make it yours

Settings has an Effects pane for the pointer, a Layout pane for the wings and the expanded view, and a Menu bar pane: when macOS hides the menu bar, which of Apple's own items show, and a divider that hides every item to its left, placed with a slider.

Takes the pointer in

Move into the island and the pointer disappears. Moving the mouse leans the island instead, and the rim lights up where it would come out.

Lets it out your way

A firm push frees the pointer through the rim on that side, and it keeps moving in the same motion. Choose what marks the spot: a ripple around the rim, a ring of light, a reflection across dark glass, or nothing. A haptic tap on release is a switch.

Push as hard as you like

A slider sets how much travel it takes to get out. Or skip the hold, and the pointer comes straight back out with the next movement.

Knows when you let go

On the trackpad the island keeps its lean while a finger is down and settles when it lifts. The pointer is kept off the top edge of the screen while held, so the menu bar stays put.

Create one

A plugin is a folder with a manifest and a program. Put it in the plugins folder (Settings, Plugins, Open plugins folder) and it starts. The fifteen shipped plugins are the reference.

plugin.json
{ "protocol": 1, "id": "coffee", "name": "Coffee", "symbol": "cup.and.saucer.fill", "run": "coffee.sh",
  "settings": [{ "key": "goal", "title": "Daily goal", "type": "number", "default": 3 }] }
coffee.sh
# one JSON object per line, each replacing one thing
read start                               # {"event":"start","settings":{...},"dataDir":"..."}
echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "2"}]}}'
echo '{"hud": {"symbol": "cup.and.saucer.fill", "tint": "orange", "text": "Coffee logged"}}'
echo '{"section": {"title": "Coffee", "rows": [{"id": "log", "title": "Log a cup"}]}}'
while read event; do                     # {"event":"click","row":"log"}
  case "$event" in *'"click"'*) echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "3"}]}}';; esac
done

A plugin prints wing for its badge, hud for an overlay, section for its expanded section, sound, activate to bring an app forward and open for a file or URL. Clicks, drops, copies and settings arrive on its stdin.

The manifest can set an interval to run once per interval instead of staying running, accepts for file drops or clipboard changes, a default side, opens for the app its title brings forward, and settings, which Settings turns into a form. Plugins run as you, with your permissions. The full protocol is in the README.

Install

macOS 14 or later, on a Mac with a notch.

Terminal
# clone, build a release bundle and launch it
git clone https://github.com/zenodea/sylt.git
cd sylt
make open

Right-click the island for Settings. Each permission is asked for the first time something needs it:

  • Accessibility for the volume and brightness keys, mirrored notifications, and raising an agent's terminal.
  • Calendar for the next event.
  • Bluetooth for device connections and battery.
  • Automation (Spotify, Music) for artwork and transport.
  • Full Disk Access for video artwork from Firefox.
