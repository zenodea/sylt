Sylt

A dynamic island for the MacBook notch. Status in two wings, short overlays for changes, and an expanded view with controls. It stays above every window, including the lock screen.

Install View on GitHub

Features

Closed, the island hugs the notch and shows only live state in two wings. What comes from the system is part of the app: each change shows as a short overlay out of the notch, and a one-sided overlay never touches the other wing. Every kind can be switched off in Settings, and a slider sets how long they stay. Select anything to see it on the island.

Two wings

Each wing is sized to its own content, and an empty side adds nothing.

Sound and light

Volume, brightness and mute use the right wing only, and a track change keeps both wings and adds a title row.

Power and connections

Battery levels and the charger, Bluetooth devices with their charge, the network link, and the Mac running hot.

Calendar and focus

The next meeting, a Focus mode, the microphone and camera, and the keyboard.

Lock screen and notifications

The island stays on the lock screen, springs open on unlock, and can mirror Notification Center banners.

Expanded

Click or swipe down and the island opens on what is relevant, two sections to a page. Swipe sideways to turn the page; the Layout pane decides which sections share one.

How it works

Two independent wings

An overlay uses one side or both. The other side keeps its content and its width.

Above every window

The panel lives in its own WindowServer space at the lock-screen level, so it stays over full-screen apps and the login window.

Click-through

The panel accepts the mouse only while the cursor is over the island. Everywhere else, clicks reach the window underneath.

On the lock screen

The island stays visible while the Mac is locked, showing a padlock and the time. On unlock the padlock opens and a greeting replaces the time.

Built-in sources are Swift monitors with a kind of overlay each; everything else is a plugin. Now-playing data is the odd one out: MediaRemote withholds metadata from third-party apps on recent macOS, so it comes from a small adapter hosted in Apple's own perl, with AppleScript for Spotify and Music and a session-store lookup for Firefox.

Plugins

Everything else is a program that prints JSON, in any language, drawn with the same badges, overlays and sections: a timer ending, a download landing, an agent finishing. Eleven are included. Each can be switched off, and its overlays separately.

Work

Coding agents, window-manager workspaces, a terminal and Slack.

Day to day

Reminders, the time, a countdown and the weather.

Files

Downloads as they land, a shelf for files you drop on the island, and what you copied.

Make it yours

Settings has an Effects pane for the pointer and a Layout pane for the wings and the expanded view. All of it is a choice.

The pointer

Takes the pointer in

Move into the island and the pointer disappears. Moving the mouse leans the island instead, and the rim lights up where it would come out. Turn it off and the island is just a panel.

Lets it out your way

A firm push frees the pointer through the rim on that side, and it keeps moving in the same motion. Choose what marks the spot: a ripple around the rim, with its strength on a slider, a ring of light, a reflection across dark glass, or nothing. A haptic tap on release is a switch.

Push as hard as you like

A slider sets how much travel it takes to get out. Or skip the hold, and the pointer comes straight back out with the next movement.

Knows when you let go

On the trackpad the island keeps its lean while a finger is down and settles when it lifts. The pointer is kept off the top edge of the screen while held, so the menu bar stays put.

Create one

A plugin is a folder with a manifest and a program. Put it in the plugins folder (Settings, Plugins, Open plugins folder) and it starts. The eleven shipped plugins are the reference.

plugin.json
{ "protocol": 1, "id": "coffee", "name": "Coffee", "symbol": "cup.and.saucer.fill", "run": "coffee.sh",
  "settings": [{ "key": "goal", "title": "Daily goal", "type": "number", "default": 3 }] }
coffee.sh
# one JSON object per line, each replacing one thing
read start                               # {"event":"start","settings":{...},"dataDir":"..."}
echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "2"}]}}'
echo '{"hud": {"symbol": "cup.and.saucer.fill", "tint": "orange", "text": "Coffee logged"}}'
echo '{"section": {"title": "Coffee", "rows": [{"id": "log", "title": "Log a cup"}]}}'
while read event; do                     # {"event":"click","row":"log"}
  case "$event" in *'"click"'*) echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "3"}]}}';; esac
done

A plugin prints wing for its badge, hud for an overlay, section for its expanded section, sound, activate to bring an app forward and open for a file or URL. The app writes start, settings, click, button, action, drop, clipboard, remove and stop to its stdin.

The manifest can set an interval to run once per interval instead of staying running, accepts for file drops or clipboard changes, a default side, and settings of type bool, text, number or choice, which Settings turns into a form. Plugins run as you, with your permissions; scripts without an executable bit run through the interpreter their extension implies. The full protocol is in the README.

Install

macOS 14 or later, on a Mac with a notch.

Terminal
# clone, build a release bundle and launch it
git clone https://github.com/zenodea/sylt.git
cd sylt
make open

# run the tests
make test

Right-click the island for Settings, including Open at login. Each permission is asked for the first time its plugin needs it, and each plugin can be switched off:

  • Accessibility: to take over the volume and brightness keys, mirror notifications, and raise an agent's terminal window.
  • Calendar: for the next event.
  • Bluetooth: for device connections and battery.
  • Automation (Spotify, Music): for artwork and transport.
