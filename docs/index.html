Control Island

A dynamic island for the MacBook notch. Status in two wings, short overlays for changes, and an expanded view with controls. It stays above every window, including the lock screen.

Install View on GitHub

Built in

Twelve sources are part of the app because they use system APIs. Select one to see it on the island.

Plugins

Everything else is a program that prints JSON, in any language. Six are included.

Settings declared in the manifest appear as a form in the app. Clicks, buttons, file drops and clipboard changes are delivered as events. Each plugin can be switched off, and its overlays can be switched off separately. Plugins run with your user permissions.

Create one

Put this folder in the plugins folder (Settings, Plugins, Open plugins folder). It starts immediately.

# plugin.json
{ "protocol": 1, "id": "coffee", "name": "Coffee", "symbol": "cup.and.saucer.fill", "run": "coffee.sh" }

# coffee.sh
read start
echo '{"wing": {"side": "right", "items": [{"symbol": "cup.and.saucer.fill", "text": "2"}]}}'
echo '{"hud": {"symbol": "cup.and.saucer.fill", "tint": "orange", "text": "Coffee logged"}}'
echo '{"section": {"title": "Coffee", "rows": [{"id": "log", "title": "Log a cup"}]}}'

The full protocol is in the README.

How it works

Two independent wings

An overlay uses one side or both. The other side keeps its content and its width.

Above every window

The panel lives in its own WindowServer space at the lock-screen level, so it stays over full-screen apps and the login window.

Click-through

The panel accepts the mouse only while the cursor is over the island. Everywhere else, clicks reach the window underneath.

On the lock screen

The island stays visible while the Mac is locked, showing a padlock and the time. On unlock the padlock opens and a greeting replaces the time.

Make it yours

Settings has an Effects pane. Everything the island does with the pointer is a choice.

Takes the pointer in

Move into the island and the pointer disappears. Moving the mouse leans the island instead, and the rim lights up where it would come out. Turn it off and the island is just a panel.

Lets it out your way

A firm push frees the pointer through the rim on that side. Choose what marks the spot: a ripple around the rim, a ring of light, a reflection across dark glass, or nothing.

Push as hard as you like

A slider sets how much travel it takes to get out. Or skip the hold, and the pointer comes straight back out with the next movement.

Knows when you let go

On the trackpad the island keeps its lean while a finger is down and settles when it lifts. The menu bar stays put the whole time the pointer is held.

Install

macOS 14 or later, on a Mac with a notch.

# clone, build a release bundle and launch it
git clone https://github.com/zenodea/controlisland.git
cd controlisland
make open

# run the tests
make test

Right-click the island for Settings, including Open at login. Each plugin asks for its permission the first time it needs one, and each can be switched off.
